01

Overview

The Orphanage Management System (OMS) is a comprehensive web-based platform built to replace manual, paper-based orphanage operations with a secure, centralised digital solution. It brings all stakeholders — administrators, staff, donors, and prospective adoptive parents — onto a single system with clearly scoped permissions.

The system manages the complete lifecycle of a child in the orphanage: admission, health & education tracking, performance reporting, and ultimately adoption. It simultaneously handles staff scheduling, leave management, task assignment, performance evaluation, and donation processing (monetary, food, clothing).

Built with a decoupled REST API backend (Flask) and a React SPA frontend (Vite), the application enforces strict role-based authentication via Flask-Session, ensuring each user type sees only the data and actions relevant to their role.

03

Key Features

Four user roles, each with a scoped dashboard:

Admin
Staff
Donor
Person (Adoptive)
👶
Child Management
Add, update, and track children — health status, education level, yearly performance (marks, attendance, remarks), and profile images. Adoption status tracked automatically.
👨‍👩‍👧
Adoption Workflow
Prospective parents browse available children, submit adoption requests, and schedule meetings. Admins review, approve or reject with official remarks.
💰
Donation Management
Donors contribute money, food, or clothing. Admins track donation status, log usage (education, medical, food, salary), and maintain financial transparency.
👩‍💼
Staff Management
Admin manages staff profiles, designations, salary, and performance ratings. Staff can apply for leaves and view assigned tasks with due dates.
🔔
Notification System
In-app and email notifications keep all users informed of request approvals, task updates, and donation confirmations in real time.
📈
Analytics Dashboard
Interactive charts (Chart.js + Recharts) visualise donation trends, admission stats, staff performance, and activity logs for data-driven decisions.
🎉
Activities Tracking
Log orphanage activities — sports, cultural, and national events — with date, type, and description for programme records.
🔐
Secure Auth & RBAC
Session-based authentication with role decorators protects every API endpoint. Each portal is completely isolated by user role.
